AI Integration
MCP Server & Tools

The MCP server exposes 8 tools that let any AI client read and manage your personal Google Tasks.

Server URL:  https://tasks.tesh.ai/mcp/   ·  Auth: Per-user API key (generate one at tasks.tesh.ai/mcp/setup.php)  ·  Protocol: JSON-RPC 2.0 over Streamable HTTP
GET
tasks_list_tasklists
Returns all your Google Task lists with their IDs and titles.
GET
tasks_list_tasks
Lists tasks in a given list. Includes title, notes, due date, completion status, and subtasks.
GET
tasks_get_task
Fetches full detail for a single task by list ID + task ID.
POST
tasks_create_task
Creates a new task in a list. Supports title, notes, due date, and optional parent task (for subtasks).
PATCH
tasks_update_task
Updates a task's title, notes, or due date. Partial updates — only send what you want to change.
POST
tasks_complete_task
Marks a task as completed (or un-completes it). Updates the status and completion timestamp.
PATCH
tasks_star_task
Stars or un-stars a task, surfacing it in the Priority Card on the web app.
PATCH
tasks_add_ai_note
Appends a timestamped AI-generated note to a task's notes field without overwriting existing content.
POST
tasks_move_task
Moves a task to a different position within its list, or to a different list entirely.
How a request flows
1 🤖
AI Client
Sends JSON-RPC POST with tool name + args
→
2 🔑
Auth Check
Validates API key, resolves user ID from key file
→
3 🎟️
Token Load
Loads OAuth token for that user; auto-refreshes if expired
→
4 ☑️
Google Tasks API
Calls tasks.googleapis.com on behalf of user
→
5 📤
JSON Response
Returns result to AI client
